# Baritone

## What is this fork? 
This will be used to advance my forked version of mindcraft, but bring higher intelligence for computers that have better hardware by using a custom fork of baritone. It changes how it moves to become more human like, without the janky movement while having features that just make sense. 

Examples:
#mine 64 wood -> applies to every possible type of wood
#mine 5 iron_ore -> applies to every possible type of iron ore like deepslate or any other types

Custom:
#sleep -> finds nearest bed and goes to sleep
#craft -> finds nearest crafting table and interacts with it
